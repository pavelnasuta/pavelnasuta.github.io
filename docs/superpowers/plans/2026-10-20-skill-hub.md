# Skill Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the existing three public skill pages into an indexable Skill Hub at `nasuta.ru/skills/`, backed by a registry and a review-only nightly release pipeline.

**Architecture:** A structured private registry drives deterministic static HTML for the hub and future skill cards. The existing individual pages remain the initial published entries; all future public skills enter through a privacy-review state machine and a thin multi-agent adapter contract. A scheduled job prepares one candidate at night but has no authority to publish site or GitHub changes.

**Tech Stack:** Python standard library, static HTML/CSS/vanilla JavaScript, Python `unittest`, GitHub Pages, Hermes scheduled jobs.

**Spec:** `docs/superpowers/specs/2026-10-20-skill-hub-design.md`

## Global Constraints

- The canonical production origin is `https://nasuta.ru`; the hub route is `https://nasuta.ru/skills/`.
- All visible card copy is Russian; English appears only in stable slugs, agent/product names, public GitHub README and useful discovery metadata.
- A visible skill must have a complete local page, non-empty SEO metadata, valid JSON-LD, an exact sitemap URL, a category, tags and compatibility statuses.
- Only a real open-source repository may produce a public GitHub link. `private-pilot` pages route visitors to the contact page instead.
- `withheld` records, personal data, credentials, local machine paths, closed-service instructions and personal defaults must never be rendered or copied to a public package.
- Compatibility badges may say only `verified`, `compatible`, `planned` or `not-applicable`; never imply a tested adapter that does not exist.
- The scheduled job processes one skill per run, creates no public remote, performs no push and sends only a review request after a passed privacy check.
- Every generated or edited page must pass `python -m unittest discover -s tests -v` and `git diff --check` before a commit.

```python
SAFE_SLUG = re.compile(r"[a-z0-9]+(?:-[a-z0-9]+)*\Z")
AGENT_STATES = frozenset({"verified", "compatible", "planned", "not-applicable"})
PUBLIC_STATUSES = frozenset({"released", "private-pilot"})


def public_items(items: list[dict[str, Any]]) -> list[dict[str, Any]]:
    return [item for item in items if item["visibility"] == "public" and item["page_url"]]


def validate_registry(items: list[dict[str, Any]]) -> None:
    seen: set[str] = set()
    for item in items:
        required = {"slug", "name", "summary", "category", "tags", "status", "visibility", "source_status", "compatibility", "updated", "version", "license", "repository_url", "page_url", "privacy_review", "release_notes", "release_priority"}
        missing = required - item.keys()
        if missing:
            raise ValueError(f"Incomplete record: {item.get('slug', '<unknown>')}: {sorted(missing)}")
        if not SAFE_SLUG.fullmatch(item["slug"]) or item["slug"] in seen:
            raise ValueError(f"Invalid or duplicate slug: {item['slug']}")
        seen.add(item["slug"])
        if set(item["compatibility"]) != {"hermes", "claude-code", "codex", "opencode", "agents-md"}:
            raise ValueError(f"Incomplete compatibility map: {item['slug']}")
        if not set(item["compatibility"].values()) <= AGENT_STATES:
            raise ValueError(f"Invalid compatibility state: {item['slug']}")
        if item["visibility"] != "public" and item["repository_url"]:
            raise ValueError(f"Non-public record has public repository URL: {item['slug']}")
```

def render_card(item: dict[str, Any]) -> str:
    badges = "".join(
        f'<span class="agent-badge agent-badge--{state}">{html.escape(agent)}</span>'
        for agent, state in item["compatibility"].items()
    )
    tags = "".join(f'<li>{html.escape(tag)}</li>' for tag in item["tags"])
    return f'''<article class="skill-card" data-category="{html.escape(item['category'])}">
      <p class="skill-card__meta">{html.escape(item['status'])} · {html.escape(item['category'])}</p>
      <h2><a href="{html.escape(item['page_url'])}">{html.escape(item['name'])}</a></h2>
      <p>{html.escape(item['summary'])}</p>
      <ul class="skill-card__tags">{tags}</ul>
      <div class="skill-card__agents" aria-label="Совместимость с агентами">{badges}</div>
    </article>'''
```

def scan_public_text(text: str) -> list[str]:
    findings = []
    if re.search(r"/(?:root|home|srv)/", text):
        findings.append("absolute-path")
    if re.search(r"(?i)(api[_-]?key|token|password|private key)", text):
        findings.append("secret-marker")
    return findings


def prepare_candidate(queue: Path, *, slug: str, output: Path) -> dict[str, object]:
    item = next(entry for entry in load_queue(queue) if entry["slug"] == slug)
    if item["decision"] != "approved-for-preparation":
        raise ValueError("Candidate lacks approval for preparation")
    draft = output / slug
    draft.mkdir(parents=True, exist_ok=False)
    return {"slug": slug, "status": "review-ready", "findings": [], "draft_path": str(draft), "requires_pavel_review": True}
```

The script must never call GitHub, run `git push`, edit the public site, access credentials or write outside its explicit output directory. It should block `review-ready` when scans find a concern and emit a `blocked` record instead.
