Adaptive English
Tutor

Помогает вернуть английский через свободную переписку, короткие занятия и голосовые. Навык хранит только учебное резюме с согласия пользователя, чтобы продолжить с того места, где остановились.

Что уже работает

Навык начинает с короткой диагностики по отдельным навыкам: чтению, письму, аудированию и речи. Дальше можно выбрать свободный разговор или занятие с небольшой целью. После разговора он сохраняет только повторяющиеся ошибки, полезные выражения и точку остановки.

Последнее существенное обновление: 30 октября 2026. Версия 0.1.0 · MIT.

Возвращает язык через разговор, а не через бесконечный дрилл.

В свободном режиме вы переписываетесь на интересные темы. Навык не перебивает каждую фразу, а собирает несколько действительно важных правок и объясняет их после естественной паузы. В режиме занятия есть одна цель и короткая проверка в конце.

НА СТАРТЕЦель, интересующие темы, язык объяснений, отношение к голосовым и согласие на файл прогресса.
В ПРОЦЕССЕДиалог, короткая практика, чтение и словарь в собственных примерах, а не отдельными списками.
ПРОВЕРКАСопоставимая задача в конце цикла, чтобы видеть прогресс по фактам, а не по числу сообщений.

Сценарии

Подходит тем, кто когда-то учил английский и хочет восстановить понимание, словарь и письмо. Можно обсуждать работу, технологии, книги или повседневные темы. Голосовые сообщения помогают постепенно возвращать речь: навык даёт текстовую расшифровку, отмечает понятность и предлагает более естественные формулировки.

Быстрый старт в Hermes

Подключите репозиторий как источник навыков и установите пакет целиком. Шаблон файла прогресса и справочные материалы придут вместе с ним.

hermes skills tap add pavelnasuta/adaptive-english-tutor
hermes skills install pavelnasuta/adaptive-english-tutor/skills/adaptive-english-tutor

На первой встрече навык уточнит задачу, интересы и удобный формат практики. Файл прогресса создаётся только после явного согласия и в месте, которое выбирает сам пользователь.

Совместимость

Hermes

Проверенная установка через GitHub tap. Навык использует штатные инструменты Hermes для диалога, файлов состояния и разбора доступных голосовых сообщений.

Другие агенты

В версии 0.1.0 нет отдельных адаптеров для Claude Code, Codex или OpenCode. Репозиторий можно читать как спецификацию, но готовую интеграцию он пока не обещает.

Как идёт практика

  1. Сформулировать ближайшую задачу и договориться о формате обратной связи.
  2. Собрать короткую стартовую картину по доступным навыкам языка.
  3. Выбрать свободный разговор или короткое занятие с проверяемым результатом.
  4. Сохранить только учебные выводы: паттерны ошибок, активные фразы и точку остановки.
  5. В конце цикла выполнить сопоставимую задачу и решить, что менять дальше.

Границы, которые нужны для нормальной практики

Навык не определяет официальный уровень CEFR и не заменяет экзаменатора. Он не обещает бессрочно помнить историю чата. Если нужен устойчивый контекст, используется отдельный файл состояния.

Публичный репозиторий не публикует переписки и голосовые. По умолчанию в учебный файл не попадают сырые чаты, записи и расшифровки. Для хранения даже краткого учебного резюме нужно согласие пользователя.
