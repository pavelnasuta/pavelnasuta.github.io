Book Summary
Skill

Помогает подготовить проект для саммари книги или аудиокниги: выбрать язык, длину и правила проверки. Полный конвейер для текста, озвучки и файлов ещё развивается.

Что уже работает

В репозитории есть настройки проекта и адаптеры для Hermes, Claude Code и Codex. Извлечение книги, сборка саммари, озвучка, PDF и MP3 пока описаны как следующий этап, а не выданы за готовую функцию.

Начинает с книги и заканчивает проверяемым планом работы.

Skill нужен для книги, электронного издания или аудиокниги. Он задаёт, что считать источником, как сохранить покрытие и что проверить в будущем саммари.

НУЖНО ДАТЬКнигу, документ или аудиокнигу с надёжной расшифровкой.
СЕЙЧАС ВЫЙДЕТНастроенный проект с языком и целевой длиной.
ПРОВЕРКАБудущее саммари нужно сверять с именами, числами, связями и структурой книги.

Сценарии

Используйте навык, когда нужно собрать из книги или аудиокниги самостоятельный материал для чтения, обучения или личной практики. Он подходит для одной книги за раз и требует легального доступа к исходнику или расшифровке.

Быстрый старт

Репозиторий запускается как обычный проект: он спрашивает язык саммари и целевую длительность аудио, а затем сохраняет выборы в отдельной конфигурации проекта.

git clone https://github.com/pavelnasuta/book-summary-skill.git
cd book-summary-skill
python scripts/project_config.py ./projects/my-book

В результате появится project.json с выбранным языком и длительностью. При возвращении к тому же проекту настройки не спрашиваются заново.

Подключение к AI-агенту

В репозитории есть адаптеры под три среды. Они используют одну общую структуру проекта и не создают три разных конвейера.

Hermes

Установите адаптер из GitHub, затем работайте с клонированным репозиторием и его общими скриптами.

hermes skills install pavelnasuta/book-summary-skill/agents/hermes

Claude Code

Поместите адаптер в проект как .claude/skills/book-summary/SKILL.md и сохраните рядом общие scripts/ и specs/.

Codex

Добавьте правила из agents/codex/AGENTS.md в рабочий AGENTS.md проекта.

Полный маршрут

  1. Создать проект и явно задать язык и длительность.
  2. Извлечь текст книги или подготовить надёжную расшифровку аудиокниги.
  3. Разбить источник на устойчивые фрагменты и сохранить покрытие.
  4. Собрать саммари по главам и проверить ключевые утверждения.
  5. Подготовить PDF, FB2, текст озвучки и единый MP3.
  6. Проверить, что структура, факты и длительность соответствуют источнику и задаче.

Этот маршрут намеренно разделяет черновик, проверку и публикацию: убедительный текст без проверки — не готовый результат.

Границы и права

Skill создаёт оригинальное преобразование, а не замену книге. Источники, расшифровки и пользовательские результаты по умолчанию остаются приватными. Публикация или распространение требуют отдельной оценки прав на исходный материал.

Перед изменением общей логики репозитория запускаются офлайн-тесты:

pytest tests/ -q
